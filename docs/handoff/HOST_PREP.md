3. **`?level=N`** (1-based, authored levels) opens that level directly, skipping the title, even when the local save has it locked. Without the param the standalone game is unchanged.

No root-absolute URLs anywhere (models, fonts, audio, workers, extra HTML entry points such as `campaign.html`). If the game has several HTML entry points, `index.html` must reach the authored campaign that `?level=N` opens.
5. **`workbook/poster.jpg`:** a real 1600×900 JPEG gameplay capture of the current build (150–300 KB), with no debug overlays. Commit it unless the repo ignores captures; then say so.
6. **Tests:** `tests/host-embed.mjs` like pie-duel's: a localhost parent page iframes the built game at `?level=N` and asserts `ready` → `level-start` → `level-complete` after a real win through the game's own input (never an injected win state), and that standalone play posts nothing.
